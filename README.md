# Proyecto Parcial 2 Cómputo Paralelo y Distribuido

Proyecto en Python para la implementación del manejo de computo en paralelo. Mediante el manejo de peticiones a APIS se realiza
un procesamiento de datos para alimentar un modelo de predicción con la finalidad de calcular el tiempo de retraso que un avión
puede llegar a tener. El modelo utilizado considera tanto datos de la aerolínea como de factores meteorológicos. El usuario se le
permite interactuar con el modelo mediante un dashboard interactivo además, de poder monitorear variables estadísticas.
